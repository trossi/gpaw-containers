# gpaw-containers

Docker images that package the GPAW stack for Roihu:

| Image            | Dockerfile              | Architecture                           |
|------------------|-------------------------|----------------------------------------|
| `gpaw-roihu-cpu` | `roihu-cpu/Dockerfile`  | `linux/amd64` — x86_64 / AMD Zen5      |
| `gpaw-roihu-gpu` | `roihu-gpu/Dockerfile`  | `linux/arm64` — aarch64 / NVIDIA Grace |
